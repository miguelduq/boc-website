5. O que foi removido e por quê

Technology Training

O Q&A (pergunta 20) diz que ainda não é um serviço ativo. Pode voltar quando começar a ser vendido.

Cloud Computing como serviço separado

Cloud virou a base das soluções end-to-end (Azure, AWS, Fabric), como sugere a estratégia.

“0+ projetos / 0+ clientes”

Transmitia a mensagem oposta à desejada. Troquei por números reais que o site já comprova.

Texto interno visível ao público

Na página do case aparecia “The design is ready for verified metrics to be added later…”. Foi trocado por uma frase para o cliente.

6. O que só vocês podem completar

Coisas que deixariam o site ainda mais forte, mas que dependem de informação real do time.

Números do case

Ex.: “de 8 horas para 20 minutos”. O Q&A confirma que os cases podem ser divulgados, mas não traz os valores.

Imagens do projeto

O card do case ainda mostra “Project cover: temporary image” e o caminho do arquivo para o visitante.

Logos das certificações

As imagens já estão em public/certfications, mas os cards ainda usam um ícone genérico.

História do nome

A pergunta “por que essa empresa nasceu” ficou sem resposta. Se existir uma história, ela entra muito bem no Who we are.
